# CampusLife (COMPX202 Assignment One)

A responsive Android app for the University of Waikato that showcases four
student service areas: **Facilities**, **Events**, **Clubs** and **Support**.

Built as an **Empty Views Activity** in **Java** with a minimum API level of
**24 (Android 7.0 Nougat)**.

## Features by assignment part

| Part | What was done |
|---|---|
| A | Created the Android app and pushed the empty project with Git |
| B | Responsive portrait XML layout (banner + 2x2 button grid), no hard-coded sizes |
| C | Added colours, a button colour selector, renamed the app to CampusLife and set the launcher icon |
| D | Landscape layout with the four buttons in a single row |
| E | onClick events with a Toast on each ImageButton |
| F | Created DetailActivity and its responsive layout |
| G | Explicit Intent that starts DetailActivity and passes a unique identifier |
| H | DetailActivity populated from arrays.xml using the passed index (no if/switch) |
| I | Structured, commented and maintainable code |

## Running

Open this folder in Android Studio, let Gradle sync, and press **Run** on an
emulator or device.
